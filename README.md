# Wish Design KV Skill

将活动策划、PPT 草稿、电商运营需求、参考截图或详情页策划稿，整理为可直接用于 Image2 的中文成品提示词。

## 核心能力

- 自动判断 KV 与 PDP／详情页物料类型，并进入对应流程
- KV 保留固定字段：方案、主题总述、顶部预留、主标题、利益点、时间、画面表达、画面风格、负面要求
- PDP 支持详情页单屏、长图分屏、卖点说明、成分原理、场景适用、检测背书、痛点与使用步骤
- 将策划稿网格、批注、箭头、灰色占位框和参考图反推为完整成品画面
- 所有具体商品实体默认绑定到“图1的产品”“图1的产品合集”等准确表达
- 用户明确指定其他图片编号时，全文保持对应编号一致
- 自动清理不适合 Image2 的措辞，保留商业信息层级与版式意图
- 内置超威、西兰、贝贝健、威王的基础视觉规则
- 默认只输出最终提示词；只有用户明确要求时才生成图片

## 使用方式

在支持 Skills 的 Codex 或 ChatGPT Work 环境中调用：

```text
@Wish Design KV Skill
根据这份活动策划，整理一版 9:16 电商 KV 中文生成提示词。
```

详情页任务：

```text
@Wish Design KV Skill
根据这张详情页策划稿，整理成本屏可直接用于 Image2 的中文成品提示词。
```

## 两类输出

### KV／海报／主图／直播背景

使用完整固定结构，支持单方案与多方向提案，并保留活动标题、利益点、时间、LOGO 与产品层级。

### PDP／详情页

使用专用分区结构，从策划稿恢复完整页面，通常包含：

- 整体风格
- 顶部标题
- 主体构图
- 内容模块或具体场景
- 排版与限制
- 针对性避免项

首屏以活动口号、产品主视觉和促销信息为主时按 KV 处理；以卖点、场景、原理、对比、检测或步骤说明为主时按 PDP 处理。

## 设计原则

1. 产品包装完整、清晰，主推产品视觉突出。
2. 商品主体、数量、组合、主次关系、包装与标签绑定对应参考图编号。
3. 严格保留策划稿中的标题、数据、单位、脚注、层级与场景要求，不擅自增加商业结论。
4. 参考图只提炼构图、色调、材质与氛围，不复制无关文字、水印或样例数据。
5. 最终输出使用简洁、可执行、面向图像生成的中文视觉语言。
6. 所有字段统一执行 Image2 措辞兼容检查。
