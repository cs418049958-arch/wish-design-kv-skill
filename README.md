# Wish Design KV Skill

将活动策划、PPT 草稿、电商运营需求、参考截图或零散品牌信息，整理为可直接用于图像生成的中文 KV 提示词。

## 核心能力

- 严格输出固定字段：方案、主题总述、顶部预留、主标题、利益点、时间、画面表达、画面风格、负面要求
- 支持电商 KV、活动海报、直播背景、Banner、活动页与产品推广图
- 支持单方案与多方向差异化提案
- 自动提取品牌、渠道、比例、产品层级、促销机制与画面重点
- 所有具体商品实体统一绑定到参考图，默认使用“图1的产品”“图1的产品合集”“图1的三瓶产品”等准确表达
- 用户明确指定其他图片编号时，全文自动保持对应编号一致
- 自动清理 PPT 网格、批注、箭头、占位框和草稿痕迹
- 自动将高风险措辞转换为兼容 Image2 的中性商业视觉语言
- 对多产品合集只控制主次、比例与清晰度，不机械锁死摆位
- 内置超威、西兰、贝贝健、威王的基础视觉规则

## 使用方式

在支持 Skills 的 Codex 或 ChatGPT Work 环境中，将本仓库放入技能目录，并通过以下方式调用：

```text
@Wish Design KV Skill
根据这份活动策划，整理一版 9:16 电商 KV 中文生成提示词。
```

需要多个创意方向时：

```text
@Wish Design KV Skill
基于这张 PPT 草稿输出 3 个差异化 KV 方向，保留原活动文案与产品信息。
```

默认只输出最终提示词；只有用户明确要求生成图片时，才进入图片生成。

## 输出结构

```text
方案｜方向名称

这是一张【品牌／渠道／活动／品类】比例竖版或横版KV……

顶部预留：……
主标题：《……》
利益点：《……》
时间：《……》

画面表达：将图1的产品合集放置在……，图1的主推产品视觉突出……

画面风格：……

负面要求：图1的产品包装清晰，标题与图1的产品无遮挡……
```

多方案会完整重复以上结构，并以分隔线区分，保证每个方向在场景、构图、色彩、镜头或创意机制上具有明显差异。

## 适用输入

- 活动策划文字与电商运营笔记
- PPT、表格或灰版截图
- 产品推广需求与品牌泛需求
- 参考图片与构图方向
- 多产品合集与促销活动素材

## 设计原则

1. 图1的产品包装完整、清晰，图1的主推产品视觉突出。
2. 所有具体商品主体、数量、组合、主次关系、包装与标签都必须绑定对应参考图编号。
3. 核心标题、利益点和活动时间优先保留。
4. 参考图只提炼构图、色调、材质与氛围，不要求照搬。
5. 最终输出使用简洁、可执行、面向图像生成的中文视觉语言。
6. 所有字段在输出前统一执行 Image2 措辞兼容检查。
