# Wish Design KV Skill

将活动策划、PPT 草稿、电商运营需求、参考截图或详情页策划稿，整理为可直接用于 Image2 的中文成品提示词。

## 核心能力

- 区分活动 KV／海报、主图／推广图、PDP／详情页，使用对应输出结构。
- 将策划稿中的网格、批注、箭头、灰色占位框与场景示意整理为完整成品画面。
- 商品主体、数量、组合、主次关系、包装和标签默认绑定“图1的……”；用户指定其他编号时，全文保持一致。
- 保留策划提供的核心文案、数字、时间和促销机制，不编造缺失信息；需要兼容处理的文字按技能规则中性化或留待后期排版。
- 内置超威、西兰、贝贝健、威王的基础视觉规则。
- 支持单方案与多个差异化方向。
- 默认只输出最终提示词；只有用户明确要求时才生成图片。

## 三类输出

| 物料 | 输出方式 |
| --- | --- |
| 活动 KV／海报／Banner／直播背景／活动页头图 | 保留原有结构：方案、主题总述、顶部预留、主标题、利益点、时间、画面表达、画面风格、负面要求。 |
| 主图／推广主图／推广图 | 使用专用模板，将已提供的 LOGO、标题、卖点和时间自然融入画面描述；不单列“顶部预留”“主标题”“利益点”“时间”四个字段。 |
| PDP／详情页单屏／长图分屏 | 使用语义分区，按需包含整体风格、顶部标题、主体构图、内容模块、排版与限制、避免项；不套用 KV 固定字段。 |

详情页分支支持卖点说明、成分／原理、场景适用、检测背书、痛点、对比与使用步骤等内容。首屏主要呈现活动口号、产品主视觉与促销信息时按 KV 处理；主要解释产品利益或使用信息时按 PDP 处理。

## 可选 Banbana 格式

只有明确要求“替换 banbana”“转成 banbana”“改成 banbana 提示词”等转换意图时启用。单纯提到该名称不会切换格式。

启用后输出一段连续的中文自然语言，聚焦商业产品摄影／3D 渲染、产品比例与摆放、场景、镜头、承托与接触阴影、光线、材质和配色；省略方案标题、字段标签、活动文案、时间、文字排版说明和负面词列表。关键限制转为正向的画面状态，继续遵守产品参考绑定与措辞兼容规则。

## 使用方式

在支持 Skills 的 Codex 或 ChatGPT Work 环境中调用：

活动 KV：

```text
@Wish Design KV Skill
根据这份活动策划，整理三个差异化的 9:16 电商 KV 中文生成提示词。
```

主图／推广图：

```text
@Wish Design KV Skill
根据产品图、参考图和策划稿，整理一版 1:1 推广主图提示词。
```

详情页：

```text
@Wish Design KV Skill
根据这张详情页策划稿，整理成本屏可直接用于 Image2 的中文成品提示词。
```

Banbana 转换：

```text
@Wish Design KV Skill
将这个方案转成 banbana 提示词，保留产品数量、比例与场景要求。
```

## 设计原则

1. 产品包装完整、清晰，主推产品视觉突出。
2. 商品实体绑定对应参考图编号，保持真实造型、数量和包装。
3. 保留策划的信息层级与视觉目的；不擅自添加商业结论。
4. 产品合集以大小、前后层次和主次关系组织摆放；用户明确锁定位置时遵循指定位置。
5. 从参考图提取构图、色调、材质与氛围，不复制无关文字、水印或样例数据。
6. 使用简洁、可执行的中文视觉语言，按对应分支检查格式、引用与措辞。
